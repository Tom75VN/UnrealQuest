# Area contour texture attribution

`AreaContourProfile.tga` and `AreaContourProfileNeutral.tga` are generated by
UnrealQuest's `tools/make_area_contour_textures.py`. No source PNG is bundled.

The clustering and rounded-hull construction were adapted from Questline's
`tools/contour-assets.js`; the per-cell signed-distance rendering replaced
its 16-mask marching-squares atlas.

The normal strip reproduces the colour and opacity profile of
Blizzard's Forever FrameXML quest-blob brushes: `UI-QuestBlob-Inside` supplies fill RGB
`57,109,255`, while `UI-QuestBlob-Outside` supplies border RGB `104,187,255`
and the 16-sample alpha ramp `220,198,155,113,82,53,34,16,5,0,0,0,0,0,0,0`.
Forever's `QuestBlobPinMixin:OnLoad` applies fill alpha 128 and border alpha
192; the generator bakes those values into a profile of signed distance and
box-filters it over one cell per level. The dark inner transition is an
UnrealQuest visual match to the supplied Forever map reference rather than a
colour sampled from either source brush. The neutral strip retains the same
alpha profile in tintable colours.
